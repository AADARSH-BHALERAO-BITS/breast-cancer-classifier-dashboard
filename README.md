# Tumor Diagnosis Classifier Dashboard — ML Assignment 2

## a. Problem Statement

Binary classification task: predict whether a breast tumor is **malignant (0)** or **benign (1)** from 30 numeric measurements taken from a digitized FNA image. Five supervised classifiers are trained independently and compared through an interactive Streamlit dashboard.

## b. Dataset Description

- **Name:** Breast Cancer Wisconsin (Diagnostic) Dataset
- **Source:** UCI ML Repository / `sklearn.datasets.load_breast_cancer`
- **Instances:** 569
- **Features:** 30 numeric — mean, SE, and worst values of 10 cell-nucleus measurements (radius, texture, perimeter, area, smoothness, compactness, concavity, concave points, symmetry, fractal dimension)
- **Target:** `diagnosis` — 0 = malignant, 1 = benign

### Observations

| ML Model Name | Observation |
|---|---|
| Logistic Regression | Very strong across the board with the highest AUC (0.9974). Tumor measurements separate nearly linearly once standardized, suiting a linear boundary. |
| Decision Tree | Solid accuracy but weakest AUC (0.9602) — a single tree's hard splits don't rank borderline cases as well as ensemble or probabilistic models. |
| kNN | Best overall — perfect recall (1.0), highest F1 and MCC. Distance-weighted voting with 7 neighbors works exceptionally well on this well-separated, standardized dataset. |
| Naive Bayes | Weakest on accuracy/F1/MCC. The Gaussian independence assumption is a poor fit given correlated features (radius, perimeter, area). |
| Random Forest | Matches Logistic Regression on all metrics; bagging corrects the single tree's overfitting weakness. |
| **Overall Winner** | **kNN** — best Recall, F1, and MCC; zero false negatives on the test split. |

## e. Streamlit App Features

- Upload `test_data.csv` (the held-out test split)
- Dropdown to switch between the five trained classifiers
- Live metrics: Accuracy, AUC, Precision, Recall, F1, MCC
- Confusion matrix heatmap and full classification report
- "Run All Classifiers" button to score every model at once

## f. How to Run Locally

```bash
pip install -r requirements.txt
cd model
python run_all_experiments.py   # trains all five models, writes leaderboard.csv
cd ..
streamlit run app.py
```

Each model can also be run individually:

```bash
cd model
python knn_model.py
```
